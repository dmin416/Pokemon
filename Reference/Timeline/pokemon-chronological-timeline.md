# Pokémon Chronological Timeline

**Year 1 = Ash Ketchum leaves Pallet Town.**

Rule: one bullet = one event at that moment. Built by atomizing every beat in pokemon-master-timeline.md, pokemon-movies-detailed.md, pokemon-games-detailed.md, pokemon-anime-detailed.md, and pokemon-dated-timeline-detailed.md.

**Hard limit:** those files do not contain episode-by-episode scripts for 1000+ anime episodes. Every event *named or summarized* in those sources is below. Untitled filler episodes are not inventable from empty sources.

Ancient whole-number Years marked **(converted)** are spine conversions of in-game “X years before the present,” not literal calendar labels printed in the games.

## Source ceiling

- Every event named or summarized in the project Timeline source files is above, plus corrections verified against shipped game/anime material where those sources were thin.
- The anime detail file is region-level, not 1000+ episode scripts. Untitled episode plots are not present in sources and are not invented here.
- To go episode-complete, add an episode database file under Reference/Timeline and it can be merged on date.
- **Intentional exclusions (not oversight):** Mystery Dungeon (Temporal Tower / Dialga and related dungeon lore), Pokémon Conquest, and Pokkén Tournament are outside this spine unless later added as their own non-spine section. They are not dated against Ash Year 1 here.
- This file merges game, anime, and movie canon into one sequence by design. Bullets that depend on only one medium are tagged where confusion is likely (for example Kitakami game lore vs Horizons anime Laqua lore).
